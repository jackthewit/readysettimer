# 짹짹이짐 ONLINE — claude.ai 공유 페이지 버전

서버 없이 claude.ai 공유 페이지(Artifact)로 돌아가는 버전입니다. 지금 운영 중인 버전이에요.

- 실시간 접속자·기구 점유·채팅·응원: Artifact `room` 기능 (topics `chat`, `cheer`는 참여자 이상)
- 부리부리 쌤 PT: Artifact `sample` 기능 (보는 사람 본인의 Claude 계정으로 답변)
- 이미지: `../public/assets/` 파일을 `assets/…` 경로로 함께 올림

## 규칙 (index.html 안의 `RULES`, `SHOPS`에서 숫자 조정)

| 항목 | 값 |
|---|---|
| 기구 | 샵마다 6개, 한 기구는 한 명만 (먼저 잡은 사람 우선) |
| 동작 | 버튼·스페이스바·내 아바타를 한 번 누르면 1회 |
| 세트 | 웨이트 12회 / 필라테스 10회, 기구당 3세트 |
| 쉬는 시간 | 세트마다 1~3분 랜덤, 이때만 채팅 가능 (받는 쪽도 쉬는 중인 사람 메시지만 표시) |
| PT | 체험 1회 = 질문 3개 무료, 이후 이용권 필요 (`hasPtPass()` — 결제 연동 예정) |

체험 횟수는 지금 브라우저 저장소에 기록돼서, 브라우저 데이터를 지우면 다시 생깁니다. 결제 시스템을 붙일 때 이용권·체험 기록을 서버(또는 Artifact `db`)로 옮겨야 합니다.
